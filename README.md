# Авторский проект «Между нами» — Документация MVP 1.0

Разработанный продуктовый сайт для авторского фотопроекта **«Между нами»** — визуальных историй о связи между человеком и его питомцем.

---

## 📸 Идея проекта

> **«Между нами уже есть история. Мы помогаем её увидеть и сохранить.»**

Сайт выстроен в концепции спокойного журнального издания, авторской фотокниги и неторопливого документального фильма. Продукт продаёт не банальную портретную фотосессию животного, а сохранение жизненной истории, ритуалов, характера и невербальной близости человека и его питомца.

---

## 🛠 Технический стек

- **Фреймворк**: Next.js 16 (App Router, React 19)
- **Язык**: TypeScript
- **Стилизация**: Tailwind CSS v4 (Кастомная цветовая палитра: молоко `#F4F0EA`, беж `#E9E0D5`, графит `#2B2926`, терракота `#A96855`)
- **Шрифты**: `Cormorant Garamond` (заголовки и цитаты), `Manrope` (основной текст и навигация)
- **Иконки**: Lucide React
- **Изображения**: Next Image с оптимизацией и резервированием пропорций
- **Разделение данных**: Истории (`data/stories.ts`) и FAQ (`data/faq.ts`) полностью вынесены из компонентов верстки.

## 🚀 Запуск проекта

### 1. Установка зависимостей (при необходимости)
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сайт будет доступен по адресу `http://localhost:3000`.

### 3. Сборка production-версии
```bash
npm run build
npm run start
```

## 📩 Форма заявки и интеграция каналов

Форма предварительного знакомства реализована в файле [`components/contact-form.tsx`](file:///home/d/Comm/MezhduNami/components/contact-form.tsx).

### Текущее состояние:
- Форма работает в **демо-режиме** (отображает плашку-уведомление `Демо-режим: форма готова к подключению канала заявок`).
- Выполняет клиентскую валидацию всех обязательных полей на русском языке.
- Поддерживает состояния `loading`, `success`, `error`.
- Блокирует прокрутку страницы и закрывается по клавише `ESC` или клику вне формы.

### Подключение Telegram-бота или Webhook:
В функции `handleSubmit` файле [`components/contact-form.tsx`](file:///home/d/Comm/MezhduNami/components/contact-form.tsx#L85-L95):

```ts
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  if (!validate()) return;

  setStatus("loading");

  try {
    const response = await fetch("/api/send-lead", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(formData),
    });

    if (response.ok) {
      setStatus("success");
    } else {
      setStatus("error");
    }
  } catch (error) {
    setStatus("error");
  }
};
```

## 🎨 Соответствие гайдлайнам и критериям приёмки

- **Сюжет и интонация**: Все тексты написаны от лица «мы» / «между нами» / «наша история». Отсутствуют стереотипные рекламные клише («скидки», «успей заказать», «идеальное портфолио»).
- **Pet Concierge**: Оформлен как мягкое упоминание будущего развития бренда без кнопок заказа несуществующих услуг.
- **Адаптивность**: Протестирован на разрешениях от 375px до 1440px+ (мобильная верстка перестраивается в единый удобный вертикальный поток без горизонтального скролла).
- **Доступность**: Все интерактивные элементы имеют состояния фокуса `focus-visible`, корректные `aria-*` атрибуты и поддержку режима уменьшенного движения (`prefers-reduced-motion`).
